# autor

`autor` is the companion R package for [*Work Automation with R*](https://tigertang.org/book/).

It provides reusable datasets, helper functions, and supporting examples that accompany the workflows and techniques presented in the book. The package is designed to help readers follow along, experiment with the examples, and adapt them to their own automation projects in R.

## What is included?

`autor` includes resources that support the book, including:

- example datasets used in demonstrations
- helper functions for repeated workflow patterns
- utilities that simplify reporting and automation examples
- package-based support for reproducible learning

## Who is this for?

This package is intended for readers of *Work Automation with R* and for R users interested in practical workflow automation, reporting, and reusable analytics tools.

## Installation

```r
remotes::install_github("CodingTigerTang/autor")
```
