# autor

`autor` is the companion R package for *Work Automation with R*.

It provides reusable datasets, helper functions, and supporting examples that accompany the workflows and techniques presented in the book. The package is designed to make it easier for readers to follow along, test ideas, and adapt the examples to their own automation projects in R.

## What is included?

`autor` includes materials that support the book, such as:

- example datasets used in demonstrations
- helper functions for repeated workflow patterns
- utilities that simplify reporting and automation examples
- package-based support for reproducible learning

## Who is this for?

This package is intended for readers of *Work Automation with R*, as well as R users interested in practical workflow automation, reporting, and reusable analytics tools.

## Installation

```r
remotes::install_github("CodingTigerTang/autor")
```
